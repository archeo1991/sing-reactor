# PRD：Sing Reactor 本地 B站逐句练唱原型

## 1. 文档信息

- 产品名：Sing Reactor
- 文档版本：v0.4（按当前实现校准）
- 更新日期：2026-07-21
- 当前阶段：Windows 本地技术原型
- 运行、依赖、缓存、日志、安全细节以根目录 `README.md` 为唯一基准。

## 2. 产品定义与价值

Sing Reactor 是仅在本机运行的 B站逐句练唱工具。用户提供可信的 B站视频链接，系统尽可能取得可靠的逐句歌词时间轴，并用浏览器原生视频的真实播放进度支持跳转和反复练习。

当前核心价值是可靠连接“视频、歌词时间轴、逐句练习”，而不是录音评分或完整声乐训练平台。

## 3. 当前目标

1. 从公开字幕、在线歌词、音频校准锚点和视频识别兜底中取得尽可能可信的逐句歌词。
2. 以原生视频真实进度驱动歌词高亮、点击跳转、逐句暂停和单句循环。
3. 对无法验证的纯文本歌词或低质量识别结果宁可拒绝，不伪装成功。
4. 保持单用户、本机运行、边界明确且可维护。

## 4. 当前范围

### 4.1 已实现

- 接受并校验 B站视频链接，读取视频元数据和公开字幕。
- 匹配网易云与 LRCLIB 歌词，并按需使用采样或完整 Whisper 锚点进行验证和校准。
- 使用少量内置歌词、视频自带/自动字幕和画面 OCR 作为后续兜底。
- 准备本地浏览器可播放视频，以原生播放进度同步歌词。
- 点击歌词跳转、逐句暂停、单句循环。
- 蓝白单页 UI，当前包含链接输入、视频播放器与歌词面板。
- 后端手工歌词对齐 API 已实现，但前端没有粘贴歌词或校准入口。

### 4.2 明确非当前范围

- 浏览器录音、麦克风输入、音高/节奏检测与评分。
- 本地音频上传、本地 LRC 上传。
- 前端手工粘贴歌词、对齐或校准 UI。
- 账号、云同步、练习历史、歌单导入、移动端、教师工作台。
- 缓存管理 UI、多人服务、认证授权、配额和对外部署。
- 授权曲库或版权练习包。

## 5. 核心用户流程

1. 用户按 README 启动本机服务。
2. 用户粘贴可信 B站链接并触发识别。
3. 系统返回标题、可信歌词时间轴和本地可播放视频，或给出明确失败原因。
4. 用户播放或拖动视频，歌词按真实进度高亮。
5. 用户点击某句跳转，或使用逐句暂停、单句循环反复练习。
6. 若点击的歌词时间超出视频长度，界面在跳转时提示更换完整视频；当前不宣称识别完成后会进行全量覆盖预检。

## 6. 产品级识别原则

- **来源有序**：优先 B站公开字幕，其次在线歌词，再按需使用内置歌词、完整音频锚点、视频字幕与 OCR 兜底。
- **线上文字、ASR 时间**：没有可靠公开字幕时，正式歌词文字来自网易云/LRCLIB 等线上候选；完整 Whisper 主要提供完整词序列的 `start/end` 时间，不把其转写错字当作最终歌词。
- **语言与缓存身份**：根据线上歌词文字推断 ASR 语言提示；完整与采样语音缓存使用 schema v3，并校验模型、`languageHint` / `requestedLanguage` 和结构，空 `segments` 拒绝且不缓存。
- **全局单调序列融合**：通过有界候选与 beam/Viterbi 式路径统一处理口白、漏识别、多个 segment 合一行、一个 segment 跨多行和重复副歌；同步 LRC 原时间只作弱先验。
- **严格接受门**：综合行/字符覆盖率、平均相似度、时间跨度与分区、最长连续漏行和 ASR 质量；少量副歌命中、锚点仅集中开头或长段漏行必须拒绝。
- **插值有边界**：未匹配歌词只有在左右高置信锚点之间按规范化文字长度插值，不对头尾大段固定外推，也不用密集时间压缩伪装成功。
- **采样仅作 fallback**：完整 Whisper 不可用或序列融合拒绝时，同步 LRC 才使用三段采样固定偏移/线性校准，最终可保留原同步轴并标注 fallback；纯文本无安全轴可退则拒绝。
- **缓存与可解释性**：首次完整转写可能较慢，后续复用 schema、模型与结构均有效的缓存；结果标明 word/segment sequence mode、置信与覆盖摘要。
- **兜底有限**：视频字幕和 OCR 是尽力而为的后续路径；Live、大幅改编、口白过多或线上歌词本身错误不保证可靠对齐。

具体识别顺序、采样窗口和实现边界见 README。

## 7. 验收标准

### 7.1 功能验收

- 输入允许的 B站链接后，能返回标题与识别结果，或明确失败。
- 有公开字幕时优先采用；无字幕时按既定链路匹配、验证和兜底。
- 不采用无法验证的纯文本歌词或低质量 OCR 结果。
- 视频可用时显示原生播放器，拖动后歌词按真实进度更新。
- 点击歌词可跳转；逐句暂停与单句循环按歌词边界工作。
- 跳转到超出当前视频长度的歌词时给出明确提示。
- 后端手工歌词对齐 API 可用，但前端不出现未实现的粘贴/校准入口。

### 7.2 非功能验收

- 默认只在本机回环地址提供服务，不面向局域网或公网。
- 对输入与重定向执行严格 URL/主机/IP 校验；跨源访问遵循白名单原则。
- 低置信识别失败可解释，不输出伪造歌词。
- 播放、识别、缓存和日志边界与 README 一致，维护信息不在 PRD 重复分叉。
- 缓存内容仅用于本机练习与技术处理；不绕过平台权限，不把可访问性表述为内容授权。

安全、请求限制、缓存、日志、依赖与版权操作细节统一见 README。

## 8. 后续方向（与当前范围隔离）

以下仅为候选方向，不属于当前承诺；必须独立实现、评审和验收后才能进入当前范围：

- 前端手工粘贴歌词与可视化校准。
- 本地 LRC 或音频导入。
- 录音、音高/节奏反馈、评分和练习历史。
- 缓存可视化管理与健康检查。
- 面向多用户场景的认证、授权、配额与部署方案。
- 获得明确授权的练习内容包。
